# 🚍 Public Transportation Dashboard (Excel Data Analysis Project)

This project is a comprehensive **data analysis and dashboard** built using **Microsoft Excel** to analyze and optimize a public bus transportation system. The dashboard tracks passenger data, route utilization, demographics, and time-based trends to support data-driven decision making.

---

## 📊 Dashboard Overview

The Excel dashboard includes:

- **Key Metrics & Insights**:
  - Total passengers, trips, and revenue
  - Average riders per trip
  - Bus utilization rates (under / over / well-utilized)
  - Peak vs. off-peak hours
  - Riders by day of week, age group, gender, and occupation

- **Route & Operational Analysis**:
  - Ridership performance by route and bus
  - Occupation-based peak hours analysis
  - Revenue breakdown

- **Strategic Recommendations**:
  - Suggestions to optimize bus allocation
  - Schedule adjustments during peak hours
  - Marketing insights based on rider demographics

## 📌 Key Features

- Dynamic dashboard with slicers and filters for deep data exploration
- Conditional formatting to highlight utilization status
- Time-based ridership trends and peak hour identification
- Breakdown of ridership by demographic segments
- Clear and visually appealing layout for easy interpretation

---

## 📈 Results & Insights

- Identified **36 over-utilized** and **19 under-utilized** buses
- Peak ridership time: **11:41 AM**
- Key rider groups: **30-49 years old**, professionals, and self-employed
- Observed Year-over-Year ridership decrease of **83.5%**, highlighting critical areas for improvement

---

## ✅ Recommendations

1. Reallocate buses from under-utilized to over-utilized routes to improve efficiency
2. Increase bus service frequency during identified peak hours
3. Focus marketing efforts on professional and middle-aged demographic groups
4. Implement promotional campaigns on high ridership days (e.g., Mondays)
5. Conduct further analysis to understand the reasons behind ridership decline


---

## 📌 How to Use

1. Clone or download this repository
2. Open `Transportation_Dashboard.xlsx` in Microsoft Excel
3. Use dropdowns and slicers to interact with the dashboard
4. Analyze key metrics and use insights to guide decision making



⚠️ **Important:** After downloading the `.xlsm` file, make sure to:

1. Right-click → Properties → Check "Unblock"
2. Open in Excel and click "Enable Content"
3. Ensure macros are allowed in your Excel settings
